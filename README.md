# Rift Traveler

Rift Traveler expands Vintage Story's temporal mechanics into a connected
progression of exploration, research, transportation, chemistry, and logistics.

Players can study natural temporal rifts, triangulate travel opportunities,
establish permanent Anchors, transport cargo over great distances, recover
Temporal Residue from successful journeys, and discover advanced reactions in
the Temporal Retort.

> Rift Traveler is currently an alpha development project. Back up important
> worlds before installing or updating.

## Current release

- Rift Traveler: `0.3.0-dev.4`
- Vintage Story: `1.22.3 Stable`
- Required side: client and server

Download Rift Traveler from the
[Vintage Story Mod Database](https://mods.vintagestory.at/rifttraveler).

## Main systems

- Temporal Triangulator and native scanner HUD
- Natural-rift scanning, triangulation, and long-distance travel
- Personal Temporal Anchors
- Private Cargo Anchors and Cargo Transmitters
- Cross-dimensional cargo delivery
- Temporal Retort chemistry
- Data-driven Retort protocols
- Research leads and confirmed discoveries
- Survival Handbook integration
- Renewable Temporal Residue from natural-rift travel

## Purpose of this repository

This public repository contains player documentation, server help, recipe
authoring references, and examples. Rift Traveler's active development source
is maintained separately while the project is in alpha.

## Feedback

When reporting a problem, include:

- Rift Traveler version;
- Vintage Story version;
- single-player or multiplayer;
- steps required to reproduce the problem;
- relevant client and server logs;
- screenshots when they help explain the issue.
